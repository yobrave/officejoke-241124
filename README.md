# One-Line Office Joke: 24-Hour Sprint

One short joke about office life, 200 characters max — funniest line takes the pool. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
